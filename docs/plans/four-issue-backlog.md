## Shared contracts

### `formatRequirements` (D4=B)

**Inputs:** ingredient hint lines (existing `IngredientReqHints` / `RecipeIngredientGates`), `RecipeCard.reqNotes`, `List<Gate>` from `RecipeUnlockGates`.  
**Output:** one `REQUIREMENTS` block for Ask prompt + card footnote (dedupe; unlock lines prefixed e.g. `解鎖：`).  
**Upgrade path:** when ≥3 consumers need the same API, extract `RecipeRequirements` facade without changing the contract.

### `RecipeUnlockGates` (D6=C)

Single dual-tree class for:
- **B:** GameStages / RecipeStages / vanilla recipe unlock (soft-dep / reflection; missing mod → silent)
- **C:** KubeJS behavioral heuristic (`isAdvancementDone` near cancel / ritual start); miss → **unknown gate** string  
No pack-specific function-name allowlist as primary path.

### FTB `consume_items` resolve (D7=B)

```
resolveConsume(task, chapter, file):
  if task explicit true/false → use it
  else if chapter default consume set → use it
  else → file.default_consume_items (often false)
  else → DO NOT emit quest_submit / quest_obtain
```

Docs: Item task Consume Items; file `default_consume_items`; chapter defaults; Tristate DEFAULT inherits.  
NFWC / Forge 1.19.2 = SNBT under `config/ftbquests/`.

## Issue 4 — Quest submit/obtain ≠ 交易

### Goal
- `consume_items: true` → 繳交／Submit  
- false / default obtain → 取得／Obtain  
- Real villager/trade paths stay 交易  
- else fallback **must not** be 交易  

### Non-goals
- No new FTB task type; no full SNBT AST library  

### Touch
- `ReplyLang.humanAcquireLabel`, `PackIndex` (quest path, ingest edges, inherit resolve), light Ask prompt / fact pin, lang ×3 ×2 trees, `tests/check_human_acquire_label.py` (+ inherit fixtures)

### Commits
```
fix(acquire): distinguish quest submit/obtain from trade labels
```

### Manual test steps (you)
1. Build Forge jar → `dist` (versioned + `packai-1.19.2-forge.jar` alias) → Prism `AI_test_NFWC_DIM` mods (one packai jar; see jar-to-nfwc rule). Or runClient.
2. Enter world; open Pack AI (`;`).
3. Ask about a known **item-submit** quest item (`consume_items: true` in chapter SNBT).
4. **PASS:** reply/facts say 繳交／Submit (or equivalent); **no** 交易 for that path.
5. Ask about a **hold/detect** item task (no consume / false).
6. **PASS:** 取得／Obtain (or equivalent); not 交易.
7. Ask about a real villager trade item if available.
8. **PASS:** may still say 交易.
9. Optional: screenshot `dist/cua_acquire_labels.png`.
