- **D1（數字輸入）**：`parseNumberInput(raw, old, min, max)` 純函數：空／非數字／**負數** → **保留舊值**（唔准入 0，因為 0＝不限＝最壞方向）；數字 → 上下限夾好才寫入。上下限：**每個數字設定自帶 (min,max) 常數表**（集中一處），並加機械對照，確保同 `PackAiConfig` 現有界線一致（防止兩份真相走樣）。11 個數字設定嘅接駁點今日用嘅 `parseInt(v, 0)` 全部要消失。
