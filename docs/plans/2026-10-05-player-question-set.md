# packai 題庫（player question set）— 2026-10-05

用途：① 定義「顧問引擎」要答得到乜 ② 直接當驗收測試集（P0／P1 逐條實跑）。
標記：**包型**＝科技／魔法冒險／通用；**可推導**＝數據夠唔夠算（非機率鏈才叫「算得到」）。
鐵則：冇資料＝答「**我唔確定**」，唔准講「呢個包冇」。
