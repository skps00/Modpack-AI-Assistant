# packai 題庫（player question set）— 2026-10-05

用途：① 定義「顧問引擎」要答得到乜 ② 直接當驗收測試集（P0／P1 逐條實跑）。
標記：**包型**＝科技／魔法冒險／通用；**可推導**＝數據夠唔夠算（非機率鏈才叫「算得到」）。
鐵則：冇資料＝答「**我唔確定**」，唔准講「呢個包冇」。

## A. 合成與依賴（最通用，建議先做）

| # | 玩家問法 | 應該答咩 | 來源 | 界線 |
|---|---|---|---|---|
| A1 | 「呢件嘢點做？」 | 逐層展開到基礎材料 + 每層用咩機器 | JEI 配方 | 冇配方＝唔確定 |
| A2 | 「做呢件嘢總共要幾多鐵？」 | 全鏈數量合計（含中間物） | JEI（固定比例） | 有機率產出就標未知 |
| A3 | 「呢件嘢要邊幾部機器？」 | 閉包內全部 catalyst | JEI catalyst | 手動合成／多方塊要標明 |
| A4 | 「呢件嘢同邊啲嘢可以互換？」 | tag 同義物品 | tags | 冇 tag＝唔確定 |
| A5 | 「我有 X，可唔可以做 Y？」 | 差咩材料（差額清單） | JEI + 玩家背包 | 只看得到背包範圍 |

## 驗收用法

1. 每條題目要喺**兩個唔同類型包**（ATM8 科技／NWFC 魔法冒險）各跑一次。
2. 過關條件：答案內每個 item／數量／機器都出現喺本輪工具結果；冇資料＝答「我唔確定」。
3. 記錄：trace（`packai/trace/ask-*.jsonl`）＋答案原文，逐條對。
